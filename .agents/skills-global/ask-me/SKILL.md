# Ask Me

Read the work already done and the user's latest direction. Separate questions answerable from files, tools, or reasonable implementation judgment from decisions only the user can make. Resolve the former yourself.
Ask the highest-impact remaining question first. Carry just enough context to explain the tradeoff, recommend a direction, and state what the answer changes. Prefer a north-star decision when it settles several details; include exact names, amounts, deadlines, or irreversible consequences when they determine the answer.
Use Codex's available user-input tool for optional clarification, or a concise direct question when input is required. Ask one question at a time and adapt to the answer. Continue independent work while waiting. Do not turn this into an approval ritual or ask about decisions already authorized. Stop interviewing once the work is unblocked; record the decision in the relevant artifact and continue.
