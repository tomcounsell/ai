# Present

Resolve the content and the audience from the conversation and supplied material. Choose the shape that explains the idea: flow, comparison, timeline, causal model, architecture, or decision. Use the installed visualization skill when it offers an appropriate inline interactive artifact.
Otherwise write one self-contained HTML file with readable type, clear hierarchy, responsive layout, and embedded styles. Prefer meaningful diagrams to decorative graphics, make controls work, and avoid a slide deck stuffed into a scrolling page. Use Mermaid or native SVG for small static diagrams and actual chart data for quantitative claims.
Open or render the result with the available Codex file/browser preview and inspect it. Keep local files on absolute links. If the user needs a shareable PDF, use the PDF workflow and visually verify pagination. Do not send the page or PDF through Telegram simply because an older workflow did so. Return the preview and artifact.
