01 · How it works

How Valor works

Every chat Valor is in has one session that speaks for it. The session answers, or starts a task.

  • The kernel, deterministic code, moves each task through its stages and decides what it may do.
  • A frontier model does the work inside each stage.

Every step is a row in a Postgres ledger the system cannot edit, and a task's state is read from those rows, so a crash or a stop leaves nothing to reconcile.

Source: docs/architecture.md · docs/data.md

02 · Infrastructure

Machines and tech stack

Valor runs natively on macOS, on four Macs, one per client, each with its own kernel, ledger and chat bridges. The design target is a MacBook Air M4 with 16 GB of RAM, and no model runs on it.

StatePostgres 18 as a document store; no Redis
Kernelone Python 3.14 process, kept alive by launchd
AgentsClaude Code, one claude -p per turn; Pi as a second harness
Meteringa gateway that prices every model call
ChannelsTelegram, Slack, email, and a local chat page
