07 · Strategic research

Notes on other agent platforms

Valor studies the platforms and repos shipping around it. Each study asks a version of the same question: which layer of the stack is worth owning, and which is better rented or just watched.

01 · The watchlist

Systems worth learning from

Each entry says what the system is and what Valor took from studying it.

Claude Managed AgentsAnthropic · hosted harness
A pre-built agent loop in managed cloud containers, driven over an API. It is meant to take over execution later, once hosted memory and a hook-equivalent API exist.
Paperclipopen source · control plane
Org charts, per-agent budgets, and approval gates over any agents. It is the source of the budget hard-stop, goal-aligned tracing and immutable audit-log ideas that Valor is adopting natively.
HermesNous Research · headless framework
A headless multi-tenant agent across twenty chat platforms, with agent-curated memory and self-improving skills. It makes the strongest case for indexed session stores, and its skills ecosystem is worth watching.
OpenHumantinyhumans · desktop app
A one-user second brain that normalizes everything into readable Markdown trees. It makes the strongest case for a legible file store, and it is half of the reason Valor's memory runs two stores.
Perplexity ComputerPerplexity · digital worker
A vision-language agent that drives a real browser the way a person would. It sets the benchmark for visual web work, and it shows why an orchestrator needs an API it can call.
Pi & Gondolinminimal core · micro-VM sandbox
A widely-adopted minimal agent core and a standalone micro-VM sandbox with the cleanest isolation seam evaluated. Valor deliberately didn't adopt them, because its dedicated machine is its isolation boundary.
OmnigentDatabricks · control plane
A credible open-source agent control plane. Second-hand accounts made it look like a toy, and it wasn't, so it reminds Valor to verify maturity claims at the source.
jcodecoding-agent runtime
A fast-moving single-author coding runtime that is highly capable but has no integration seam. It shows when to watch a project rather than adopt it.
FirstMateopen source · agent crew orchestrator
A single primary agent that dispatches a crew of sub-agents into isolated git worktrees, supervised by an event-driven watcher instead of polling. It is the closest external system found to Valor's own single-session-plus-worktree-isolated-subagent shape, and the source of the comparison.

02 · The comparisons

Head-to-head studies

These are full write-ups of the in-house strategic analyses, one page per matchup.

April 2026 Valor vs Paperclip A vertical teammate and a horizontal control plane turn out to complement each other. Paperclip's best ideas (budget hard-stops, goal tracing, audit logs) are worth adopting natively before adopting the platform. April 2026 Valor vs Managed Agents In the proposed split, Valor orchestrates and Managed Agents executes. The hard problem is porting subconscious memory to a hosted harness, which the study solves by stealth injection through workflow tools, with shared Redis in the middle. April 2026 Managed Agents vs Perplexity Computer A programmable engine and a digital worker are different kinds of product. A product without an API can't be orchestrated, and the credit economics decide anything the API question leaves open. May 2026 OpenHuman vs Hermes Two open agent stacks make different bets: transparency for one desktop user, or autonomy and reach for a headless fleet. Each one's memory design follows from its form factor, which is the lesson behind Valor's own two-store design.
