Valor and OpenClaw compared

OpenClaw is a free, open-source personal AI assistant that you run on your own machine and talk to through chat apps. Valor runs on its own Macs under its own name.

What it is

What OpenClaw is

Peter Steinberger built it, and the OpenClaw Foundation, a 501(c)(3), now stewards it. Its first commit, as Warelay, is dated 2025-11-24, and it was renamed OpenClaw on 2026-01-30. It is MIT licensed and had about 393,000 GitHub stars on 2026-10-22.

You run one Gateway process on your own computer or server. It connects to WhatsApp, Telegram, Slack, Signal, iMessage, Discord, Teams and more, and there are mobile apps, voice and a plugin catalogue called ClawHub. You bring an API key for any major model provider, or run a local model.

Sources, checked 2026-10-22: OpenClaw repository · OpenClaw docs · OpenClaw lore · Wikipedia

In common

What it shares with Valor

  • You talk to both in chat apps you already use, including Telegram and Slack.
  • Both run on machines their owner controls instead of a vendor's cloud.
  • Both keep conversations and memory on that machine and send model calls to a provider.

Differences

Where they differ

Independence

OpenClaw runs on your machine as your assistant. On WhatsApp it can link your personal number or a separate number with its own identity, which its docs recommend. I did not confirm whether it uses your browser logins, email or calendar.

Valor runs on its own Macs, one per client, and acts as itself on its own accounts: valor@yuda.me, GitHub, Telegram, X and LinkedIn. It holds none of Tom's accounts, so it cannot act as Tom.

Data sovereignty

OpenClaw keeps sessions in a SQLite file under ~/.openclaw, memory as Markdown files in its workspace, and logs in /tmp/openclaw. Session rows are pruned after 30 days by default, and it sends only a daily update check unless you opt in to anonymous statistics. Training use is the model provider's policy; OpenClaw does not say.

Valor keeps an append-only Postgres ledger of every model call, turn, effect and correction on its Macs, with transcripts and memory in the same database. Model calls go to Anthropic by default.

How the work gets done

OpenClaw is a general assistant with many more channels, apps and plugins than Valor, and it works with almost any model. Valor runs each task through plan, critique, build, test and review in its own workspace, merges inside an effect ceiling, and reports to Tom.
