# Zoom Out

Recover the original objective, latest steering, plan or progress notes, and recent relevant commits. Use project-scoped memory only if the current environment actually provides it. Inspect related issue state when relevant; avoid unrelated repository-wide recon.
Compare intended outcomes with what has actually changed. Identify the central blocker, discarded assumptions, and work that can wait. After repeated patch failures, revisit the causal diagnosis before another implementation attempt.
Give a short assessment: goal, evidence of progress, blocker, recommended next focus, and what to defer. Ask for direction only where a real decision remains; otherwise act on the recommendation within the current scope. Deliver in this conversation unless the user has authorized another destination.
