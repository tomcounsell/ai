Checklist for a code artifact. The checks block holds the kernel's build and tests results from a fresh sandbox; treat them as fact and treat any "all tests pass" in the diff or the code as a claim. Read the diff in the artifacts block and the files it touches under /work. For each criterion: find the code that is meant to satisfy it and the test that would fail if it did not, and run that test or a command of your own with bash when reading is not enough; a criterion with no test that would catch its absence is not met unless the code plainly satisfies it and you say why. Check the arithmetic and the edge cases the criteria name against the implementation rather than against the tests alone, since the tests may only cover the cases that pass. Note under scope_findings any change outside the contract's premise, any non-goal the diff touches, and any file the artifacts list that the diff does not explain. Use the tool log to see what was invoked, with what exit status, and to spot a test the Executor never ran; hashes there are the record, and the output is yours to reproduce.
